このアプリのソルバーは、もともと Excel VBA で作った自動解答プログラムをもとに、Web 用に作り直したものです。人が解くときと同じ「論理だけ」で解き、仮置きしてやり直す当てずっぽう（バックトラック）は使いません。ここでは、その考え方と、Web 版で加えた工夫を紹介します。

1. ルールと考え方 2. 1列だけを解く（パターン行列） 3. 行列演算で速くする 4. Web 版の実装 5. 詰め処理（プローブ） 6. 「答えが1つに決まる問題」を作る 7. 画像からAIで読み込むしくみ

1. ルールと考え方

お絵かきロジックは、各行・各列の左（上）に書かれた数字が「黒マスが何マス続くか」を表すパズルです。数字の並び順に黒マスのかたまりが並び、かたまりの間には1マス以上の白マスが入ります。

マスの状態は「未確定・黒・白」の3つです。ソルバーは、1つの行（または列）だけを見て、どの並べ方でも必ず黒になるマスとどの並べ方でも必ず白になるマスを確定させます。これを全部の行と列について、確定するマスがなくなるまで繰り返します。

2. 1列だけを解く（パターン行列）

1列の解き方は、ブログ記事「イラストロジックの自動解答アルゴリズム 第1章」で図を使って詳しく説明しています。要点は次のとおりです。

  • 初回解答：数字の置き方をすべて並べた「パターン行列」を作り、全パターンに共通する黒・白を確定させます（例：10マスに「3 2 1」）。
  • 追加回答：ほかの行・列から黒や白が決まったら、それと矛盾するパターンを外し、残ったパターンの共通部分を新しく確定させます。
  • 連続した黒マスからの判定：つながった黒マスとその両端の状態から、そのかたまりに当てはまる数字の範囲を絞り込みます。

3. 行列演算で速くする

「第2章」では、マスの状態を「白=0・未確定=1・黒=2」の数値に置き換え、パターンの絞り込みを行列の掛け算と合計でまとめて計算する方法を紹介しています。無効なパターンを0にする行列や、開始位置・終了位置を求める連番の行列を事前に用意しておき、使い回すことで高速化しています。

4. Web 版の実装

Web 版では、同じ「1列の推理」を、パターンを全部並べずに計算する方法に置き換えています。

  • 前からと後ろからの動的計画法：「先頭からこのマスまでに、数字のいくつ目までを置けるか」と「末尾から……」を両方向に計算し、各マスについて「黒になりうるか」「白になりうるか」を求めます。計算量は（マス数 × 数字の個数）程度で、300マスの行でも一瞬で終わります。
  • 全体の流れ：行と列を交互に解き、確定したマスがあれば交差する列・行をもう一度解きます。
  • 画面を止めない：解答は Web Worker（画面とは別の処理の流れ）で動かすので、大きな問題でも画面が固まりません。1手ずつ進める「ステップ」表示にも対応しています。

5. 詰め処理（プローブ）

1列ずつの推理だけで進まなくなったら、未確定のマスを1つ選び、「黒と仮定した場合」と「白と仮定した場合」の両方でその列を解きます。両方で共通して決まるマスは、どちらの場合でも正しいので確定できます。どちらかで矛盾が出れば、もう一方が正解です。それでも2回続けて進まなければ終了します。仮定を何手も重ねる総当たりはしないので、「人が論理で解ける問題」かどうかの判定にもなります。

6. 「答えが1つに決まる問題」を作る

写真やQRコードをそのまま白黒にすると、答えが1つに決まらない（論理だけでは解き切れない）問題になりがちです。このアプリでは、解けない問題を後から直すのではなく、同じ見た目・同じ意味になる候補をたくさん作り、ソルバーで解ける割合を測って選ぶ方法をとっています。

  • 写真：しきい値（明るさの順位）、ならし（3×3 の中央値）、閉包、孤立マスの除去などを 100 通り以上試します。30〜150 マスの写真 30 ケースで試したところ、29 ケースで「そのまま答えが1つに決まる設定」が見つかりました（残り1件もマス1つの調整で完成）。
  • QRコード：同じURLでも、マスク8種類・誤り訂正4段階・URL末尾の #1〜#15 で模様が変わり、どれも同じページを開きます。これを数百通り作り、解けるものを選びます。選んだQRコードは、読み取りライブラリ（jsQR）で実際に読み取れることを確かめています。試した7種類のURLすべてで、解けるQRコードが見つかりました。

7. 画像からAIで読み込むしくみ

雑誌の問題の画像は、利用者ご自身のAI（ChatGPT・Gemini・Claude など）に読ませます。専用のプロンプトで、R1: 3 1・C1: 2 2 のように行番号つきの形式で出力させるのがポイントで、AIが行を飛ばしたり、ずれたりするのを防ぎます。貼り付けたデータは、行数・列数の過不足、ヒントが1列に収まるか、行ヒントと列ヒントの合計が一致するかを自動で確かめます。
