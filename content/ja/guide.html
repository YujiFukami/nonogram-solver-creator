「最強イラストロジック自動解答」は、お絵かきロジック（イラストロジック・ピクロス・ノノグラム）を自動で解いたり、写真やQRコードから問題を作ったりできる無料のWebアプリです。インストールは不要で、ブラウザだけで動きます。入力した問題や画像はお使いのブラウザの中だけで処理され、サーバーには送られません。

1. 問題を解く 2. 問題を読み込む（ファイル・サンプル・画像からAI） 3. 写真から問題を作る 4. QRコードから問題を作る 5. 保存と印刷

1. 問題を解く

  1. 左のメニューの「サイズ設定」で、縦と横のマス数を入れて「適用」を押します（最大300×300）。
  2. 盤面の上の入力欄に、1行目のヒントから順に入力します。数字はスペースで区切り、Enter で確定します。
  3. 入力のきまり：1〜2桁の数字はそのまま1つのヒント、3桁以上の数字は1桁ずつに分けて追加（例：312 → 3・1・2）、. で末尾を1つ削除、.. でその行を全部消す、0 で次の行へ、↑↓ で行を移動します。ヒントのマスをクリックして、その行や列に移ることもできます。
  4. 行・列すべて入力したら「▶ 解答実行」。「⏯ ステップ」で1手ずつ、「⏩ 自動」で一定の間隔で進めて、解き方を目で追うこともできます。

このアプリは人が解くときと同じ論理だけで解き、当てずっぽう（仮置きのやり直し）はしません。最後まで埋まらない場合は、問題の答えが1つに決まらないか、ヒントの入力に誤りがある可能性があります。

2. 問題を読み込む

  • ファイル：「📂 読込」で、保存した問題（.txt）を開けます。
  • サンプル：「📋 サンプルから選ぶ」で、すぐに試せる問題を読み込めます。
  • 画像からAIで読込：雑誌の問題をスマホで撮ったりスキャンしたりした画像を、お使いのAI（ChatGPT・Gemini・Claude など）に読ませて、ヒントを自動で入力できます。
  1. 「📷 画像からAIで読込」を押し、「📋 プロンプトをコピー」を押します。
  2. ChatGPT・Gemini・Claude のどれかを開き、コピーしたプロンプトと問題の画像を送ります。大きい問題は「上のヒント」と「左のヒント」に分けて撮ると正確になります。
  3. AIが返したコードブロックをコピーし、アプリの欄に貼り付けます。行数・列数の過不足や、行と列のヒントの合計が合っているかを自動で確かめ、問題があれば該当する行を示します。
  4. 「✔ 解答タブに読み込む」で解答タブに入ります。

AIは各自のアカウントで使うため、このアプリの利用料はかかりません。50×45 の雑誌の問題で、読み取ったデータから最後まで解けることを確かめています。

3. 写真から問題を作る

  1. 「問題作成」タブで「📂 画像を選択」から写真を読み込みます（ドラッグ＆ドロップも可）。元画像の上の枠で使う範囲を決めます。
  2. 「グリッド」で横のマス数を決めます（縦は自動）。最初は 30〜60 マスがおすすめです。
  3. 「🔎 解ける設定を探す」を押すと、しきい値・ならしなどの組み合わせを自動で試し、答えが1つに決まる問題になる候補を小さな絵で並べます。クリックで切り替えて、写真らしく見えるものを選びます。
  4. 盤面をクリック・ドラッグすると、マスを手で直せます。直したら「解の検証」で、答えが1つに決まるか確かめます。
  5. 「➡ 解答タブへ渡す」「💾 .txt」「🖨 印刷用PDF」で出力します。

コツ：ディザ（点描）や輪郭の方式は、答えが1つに決まりにくい傾向があります。明暗のはっきりした写真（シルエット・逆光など）ほど、写真らしい問題になります。

4. QRコードから問題を作る

  1. 「QRコード」タブでURLを入力します。
  2. 「🔎 解けるQRを探す」を押すと、同じ内容のQRコードを数百通り作り、答えが1つに決まり、実際に読み取れるものを選びます。読み取りは、作ったQRコードを画像にして確認しています。
  3. 「URLの末尾に #数字 を付けてよい」をオンにすると、見つかりやすくなります（開くページは同じです）。
  4. 「解答タブへ渡す」や「🖨 印刷用PDF」で出力します。イベントやチラシの謎解きにも使えます。

5. 保存と印刷

  • 「💾 保存」：ヒントを .txt で保存します（Excel VBA 版と同じ形式）。
  • 「🖼 画像として保存」：盤面を PNG で保存します。「ヒント数字を含む」をオンにすると、問題用紙のような画像になります。
  • 「🖨 印刷用PDF」（問題作成・QR）：用紙の向きを自動で選んで、印刷用の問題を作ります。
  • 左のメニューは「◀」でたためます。画面の広さを解答に使えます。

対応言語：日本語・英語・中国語（簡体字・繁体字）・韓国語・フランス語・ドイツ語・イタリア語・スペイン語・ロシア語・トルコ語・ポーランド語の12言語。パソコン・スマホ・タブレットのブラウザで使えます。
